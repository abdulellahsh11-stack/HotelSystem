ضيوف — نقاط القوة والضعف

تحليل مباشر لموقع منصة ضيوف مقابل السوق.

نقاط القوة

  • التكامل الحكومي 98% — شموس وزاتكا أصلياً، يتفوق على جميع المنصات العالمية
  • الشمولية 95% — 17 وحدة (PMS + POS + ERP ضيافة + موارد بشرية) في منصة واحدة
  • التعريب 97% — RTL أصلي وتجربة عربية كاملة لا تضاهيها OPERA/Mews
  • السعر/القيمة 92% — تكلفة أقل بكثير من المنصات العالمية
  • تكامل محلي — مدى / STC Pay / Apple Pay جاهزة

نقاط الضعف

  • مدير القنوات 55% — ربط OTA أولي، يحتاج نضوج (Booking/Expedia/Airbnb)
  • API 70% — موثّق لكن لا يوجد متجر تطبيقات بعد
  • الشهادات الأمنية 75% — لا توجد شهادة PCI-DSS / ISO معتمدة رسمياً بعد
  • بوابات الدفع 78% — التكامل PCI لم يكتمل بالكامل
  • سجل المراجع — منتج جديد، قاعدة عملاء محدودة

1 · نظرة عامة والمصادقة

واجهة موحّدة تتيح ربط أي برنامج خارجي أو تطبيق بمنصة ضيوف، بمرونة كاملة حسب البرنامج ورقم المشترك والصلاحيات.

المعمارية

الطبقةالوصف
المشترك (client_id)كل مفتاح API مرتبط برقم مشترك واحد — العزل التام بين المنشآت
المفتاح (API Key)يبدأ بـ dhk_ — يُخزَّن كـ SHA-256 hash + قناع فقط، لا يُحفظ خاماً أبداً
النطاقات (Scopes)صلاحيات دقيقة لكل برنامج (قراءة/كتابة) — مبدأ أقل صلاحية

المصادقة

أرسل المفتاح في ترويسة كل طلب:

# كل طلب يتطلب الترويسة:
X-API-Key: dhk_xxxxxxxxxxxxxxxxxxxx

# مثال — جلب الغرف:
curl https://www.dheuof.com/api/open/v1/rooms \
  -H "X-API-Key: dhk_xxxxxxxxxxxxxxxxxxxx"
الأمان: المفتاح يظهر مرة واحدة فقط عند الإصدار. بعدها لا يمكن استرجاعه — فقط القناع dhk_abc••••WXYZ للتعرّف عليه.

النطاقات المتاحة (Scopes)

rooms:readrooms:write bookings:readbookings:write guests:readguests:write invoices:readinvoices:write pos:readpos:write inventory:readinventory:write hr:readchannels:readchannels:write kpi:readaccounting:readaccounting:write

إدارة المفاتيح

الطريقةالمسارالوصف
GET/keysقائمة مفاتيح المشترك + النطاقات المتاحة
POST/keysإصدار مفتاح جديد (يظهر مرة واحدة)
DEL/keys/{id}إيقاف مفتاح
# إصدار مفتاح جديد (يتطلب جلسة مشترك)
POST /api/open/v1/keys
{
  "name": "تطبيق المحاسبة",
  "scopes": ["invoices:read", "invoices:write", "accounting:read"]
}
# الرد:
{
  "api_key": "dhk_fxR3...OFA8",   // احفظه الآن — لن يظهر ثانية
  "key_hint": "dhk_fxR••••OFA8",
  "scopes": ["invoices:read", "invoices:write", "accounting:read"]
}

2 · المحاسبة والفوترة ZATCA

فوترة إلكترونية متوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك — المرحلة الأولى (فاتورة).

الحقول المتوافقة مع ZATCA

الحقلالمصدرإلزامي
اسم الشركة (البائع)company_name✓ نعم
الرقم الضريبي (البائع)seller_vat✓ نعم (15 رقم)
اسم الضيف (المشتري)guest_name✓ نعم
الرقم الضريبي للمشتريbuyer_vatاختياري
الطابع الزمنيtimestampتلقائي
ض.ق.م 15%محسوبة تلقائياً✓ تلقائي

رمز QR متوافق (TLV → Base64)

▦

5 حقول مُرمّزة TLV حسب مواصفة ZATCA:

  • Tag 1: اسم البائع (اسم الشركة)
  • Tag 2: الرقم الضريبي للبائع
  • Tag 3: الطابع الزمني (ISO-8601)
  • Tag 4: الإجمالي شامل الضريبة
  • Tag 5: إجمالي ض.ق.م

4 · سيناريوهات الربط والملفات

سيناريو: ربط برنامج محاسبة خارجي

  • 1. المشترك يُصدر مفتاحاً بنطاق invoices:write + accounting:read
  • 2. البرنامج الخارجي يُنشئ فواتير ZATCA عبر POST /invoices
  • 3. يسحب الملخص المالي عبر GET /accounting/summary
  • 4. كل فاتورة تحمل QR متوافق جاهز للطباعة والتدقيق

سيناريو: تطبيق جوال للحجوزات

  • 1. مفتاح بنطاق rooms:read + bookings:read
  • 2. يعرض الإتاحة عبر GET /availability
  • 3. يتابع الحجوزات عبر GET /bookings

سيناريو: لوحة تحليلات

  • مفتاح kpi:read + accounting:read → يغذّي لوحة خارجية بالإشغال والإيرادات

الملفات المُنفّذة في هذا التسليم

الملفالوصف

routes/open_api.py16 نقطة موحّدة لكل البرامج + المحاسبة + المفاتيح

تم التحقق: جميع الحسابات الضريبية مُختبَرة (920 + 138 ض.ق.م = 1058 ر.س)، رمز QR يُولّد TLV صحيحاً، التطبيق يُقلع بنجاح مع تسجيل 16 نقطة API.

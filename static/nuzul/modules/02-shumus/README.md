# 02 — شموس · Shumūs

> **Status:** active — MOI verification add-on.

## Purpose

برنامج حكومي للتحقّق من سجل الضيف الجنائي. يربط نقطة الاستقبال مباشرة بوزارة الداخلية لتأكيد خلوّ الضيف من القضايا قبل تسليم المفتاح. **ليس مصدر إيراد** — هي طبقة أمنية وامتثال نظامي.

## Planned features

- تحقّق فوري من رقم الهوية / الإقامة / الجواز
- إشارة خضراء / صفراء / حمراء أمام موظف الاستقبال
- سجلّ تدقيق كامل (audit log) لكل عملية تحقّق
- تنبيه فوري للأمن عند نتيجة سلبية
- ربط آلي بنظام شموس الحكومي عبر API معتمد
